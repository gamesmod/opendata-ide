## Риски

| ID | Риск | Влияние | Митигирование |
|---|---|---|---|
| R1 | Внутренние API `intellij.grid` меняются между версиями платформы | поломка `grid/*` при обновлении | платформа фиксируется в `ossPlatformVersion`, реестр API ведётся в `architecture.md`, обновление выполняется отдельной задачей с прогоном тестов и smoke |
| R2 | Открытая сборка IntelliJ перестанет публиковаться в релизах `intellij-community` | нет готовой базы продукта | сборка платформы из исходников (`intellij-community`, `installers.cmd`); +5–10 чд |
| R3 | Драйверы ClickHouse и Arrow загружаются из Maven Central | нет подключения без сети | ручная установка JAR (`docs/databases.md`); при необходимости — включение драйверов в дистрибутив (+~60 МБ) |
| R4 | Несовместимость `clickhouse-jdbc` с новыми версиями сервера | ошибки чтения ответов | фиксированная версия драйвера, `compress=0`, тесты на ClickHouse в CI |
| R5 | Dremio Flight SQL без DML и с неполными метаданными | только чтение | соответствует возможностям Dremio; запись — через SQL в консоли |
