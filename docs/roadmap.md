# Roadmap и оценка трудозатрат

Оценка дана в человеко-днях (чд) для одного разработчика, знакомого с IntelliJ Platform SDK.
Диапазон «мин–макс» отражает неопределённость, которая снимется после этапа 0 на реальной установке.

## Этапы

| ID | Работа | Статус | Оценка, чд |
|---|---|---|---|
| R-0 | Каркас репозитория, Gradle, скрипты, инструмент research, тестовая БД, документация | **сделано** | — |
| R-1 | Этап 0: прогнать research на целевой установке, разобрать отчёт, заполнить решения в матрице переиспользования, реестр internal API | **сделано** (DataGrip 2026.2.6) | — |
| R-2 | Этап 1 (POC): первая сборка, Data Source, Test Connection, introspection через штатный API — **сделано** (16/16 тестов). Осталось: `run.ps1 -Poc` в UI после принятия User Agreement | почти готово | 0,5 |
| R-3 | Этапы 2–4: приёмка Console, DataGrid и Editing по `docs/acceptance.md`, устранение найденных проблем (кода почти нет, всё штатное) | ожидает | 1–2 |
| R-4 | Проверка остальных СУБД (MySQL, MariaDB, MS SQL, Oracle, ClickHouse, SQLite): штатные диалекты и драйверы, по 0,25–0,5 чд на СУБД | ожидает | 1,5–3 |
| R-5 | Dremio: в Database Tools нет штатного диалекта, нужен custom driver (Generic/«Other») и, возможно, файл драйвера в `opendata/drivers` | ожидает | 1–3 |
| R-6 | Юридическая проверка этапа 5 (лицензия на Database Tools внутри отдельного продукта) | **блокирует R-8** | 1–2 (+ юрист) |
| R-7 | Автоматизация UI-приёмки этапов 1–4 (IntelliJ Driver / Remote-Robot, сценарии DoD 1–20) | ожидает | 5–8 |
| R-8 | Этап 5: продукт OpenData IDE, вариант A (см. `opendata/product/README.md`) | после POC и R-6 | 3–5 |
| R-8′ | Этап 5: продукт OpenData IDE, вариант B (собственный product configuration в intellij-community) | после POC и R-6 | 15–25 |
| R-9 | Документация, Windows-инсталлятор и launcher, финальная приёмка MVP | ожидает | 2–3 |

## Итого

| Сценарий | Оценка, чд |
|---|---|
| MVP до этапа 4 включительно (остаток R-2, R-3) | **1,5–2,5** |
| MVP + все СУБД из ТЗ + автотесты UI (+ R-4, R-5, R-7) | **9–16,5** |
| Полный объём с продуктом, вариант A (+ R-6, R-8, R-9) | **15–26,5** |
| Полный объём с продуктом, вариант B (+ R-6, R-8′, R-9) | **27–46,5** |

## Риски

| ID | Риск | Влияние | Митигирование |
|---|---|---|---|
| R1 | Лицензия Database Tools and SQL может не допускать его использование внутри отдельного продукта с чужим брендингом, а сам плагин может требовать лицензию или активацию, привязанную к продуктам JetBrains | этап 5, вариант B может оказаться невозможен | R-6 до начала этапа 5; вариант A как запасной |
| R2 | Внутренние API `com.intellij.database.*` меняются между версиями | поломка собственного кода при обновлении IDE | использовать internal API только при необходимости, вести реестр в `architecture.md`, перед обновлением IDE повторно прогонять research и сравнивать `docs/research/api/*` |
| R3 | Несовпадение версий IPGP, Kotlin и платформы при первой сборке | задержка R-2 | `docs/build.md`, раздел «Первая сборка»; compatibility-matrix |
| R4 | Нет доступа в интернет для Driver Manager | драйверы не скачиваются | ручная установка драйвера (`docs/postgresql.md`) |
| R5 | Dremio без штатного диалекта | ограниченные completion и introspection | Generic JDBC + решение о собственном диалекте только после R-5 |
